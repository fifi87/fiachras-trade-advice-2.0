# Fiachra's Tradin 2.0

Professional stock + forex market terminal.

## Structure
- `frontend/` — public website UI
- `backend/` — secure server/API layer
- `package.json` — Node dependencies

## Important
Never place market-data API keys in `frontend/` or commit them to GitHub.

The first version intentionally shows **Live Data Not Connected** until a real provider is configured. It does not invent prices.
